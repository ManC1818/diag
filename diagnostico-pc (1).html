Diagnóstico de tu computadora

Prueba los colores de la pantalla, cada tecla del teclado, el audio de bocinas y micrófono, la cámara, el touchpad y la pantalla táctil. Todo funciona en tu navegador y nada se envía a ningún lado.

Colores y píxeles muertos

Inicia la prueba y recorre los colores con clic, espacio o las flechas. Busca puntos que no cambian de color (píxeles muertos), manchas o zonas más claras. Esc para salir.

Prueba de teclas

Presiona cada tecla. Se pone verde cuando se detecta. Si alguna no cambia, puede estar sucia o dañada.

Bocinas o audífonos

Baja el volumen del sistema antes de empezar. Debes oír el tono solo del lado que indique cada botón.

Micrófono

Habla o aplaude: la barra debe moverse. El navegador te pedirá permiso para usar el micrófono.

Cámara web

Activa la cámara y comprueba que la imagen se vea nítida, con buen color y sin retraso. El navegador te pedirá permiso.

Touchpad (o mouse)

Haz cada gesto dentro del recuadro. Cada acción se marca cuando se detecta. El pellizco para zoom se detecta como Ctrl + desplazamiento.

    Pantalla táctil

    Inicia la prueba y toca o arrastra el dedo hasta cubrir todos los recuadros, incluidos los bordes y esquinas. Prueba también con varios dedos a la vez. Si tu pantalla no es táctil, puedes practicar con el mouse.
